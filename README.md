# 见微 · 个人连续研究助手

把公司财报中的数据与用户关心的问题连起来：确认公司和报告期，读取实际财务数据，区分披露事实与推断，并说明仍缺少什么证据。研究记忆可以跨会话延续关注点和未解决的问题；用户可查看、修改、停用或删除。

[公开源码](https://github.com/rtyy5675-sys/investment-research-demo) · [源码与部署状态](docs/源码与部署状态.md)

## 当前范围

- 面向 A 股单家公司，支持年度及一季度、上半年、前三季度累计财报；比较同口径历史期间。
- 财务数据通过扶摇 MCP 查询。公司和报告期由当前任务确定，查询失败会显示失败状态。
- 可检索公告或上传文本型 PDF，补查已识别范围内的原始财报字段。
- 模型通过兼容 API 配置；运行时按证据与报告期形成回答。产品不提供股价预测或买卖建议。
- 市场预期是否已计价、多公司对比、港美股及长期用户价值不在当前已验证范围内。

## 本机运行

需要 Node.js 20.19 或更新版本。

```sh
npm ci
npm start
```

打开 `http://127.0.0.1:8791`。`npm start` 会构建 React 界面并启动本机服务。开发预览可在服务运行时另开终端执行 `npm run dev`。

在界面“模型 API”中配置服务地址、模型名和 API Key。数据服务凭证放在项目根目录 `.env.local`：

```env
FUYAO_API_KEY=your-key
```

`.env.local` 已被 Git 忽略。模型 Key 保存在本机 `artifacts/model-settings.json`，不会返回浏览器。连接验证只检查基础结构化输出和 MCP 工具发现；完整研究仍需按实际任务检查。
