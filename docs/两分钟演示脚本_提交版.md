# 两分钟演示脚本

原题视频可选；本文件是提纲，不是已录制的视频。可展示已保存的真实运行，并明确是回放，避免模型等待超过视频时长。

| 时间 | 操作 | 重点 |
| --- | --- | --- |
| 0–15秒 | 主对话、研究关注 | 面向反复研究同一公司的投资者，不要求先填写画像或表态。 |
| 15–35秒 | 展开先前结果 | 上次只有现金流净额，缺分项，无法拆分。 |
| 35–65秒 | 原始财报入口及成功版 | 按公司/期间检索或上传，共用核验。 |
| 65–90秒 | 点瀑布图、切数据、开原文 | 新证据具体解决了什么；算术变化和经营原因分开。 |
| 90–105秒 | 美的或错误PDF记录 | 不同公司/单位/列位；错公司失败保留有效结果。 |
| 105–120秒 | 记忆控制和未决项 | 关注可续接、纠正与停用；长期价值仍待验证。 |

新环境没有本机taskId，需配置后重建；本包精选证据和截图可供阅读，不冒充可操作的远程产品。没有录视频时如实省略，不将脚本算作视频交付。
