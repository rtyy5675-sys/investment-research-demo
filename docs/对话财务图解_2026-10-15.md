# 对话里的财务图解

日期：2026-10-15。状态：已接入现有回答，构建、6项针对性数据检查及两家公司浏览器交互验收通过。

## 用户体验

研究回答取得对应数据后，直接出现“本轮财务图解”，提供三类视图：

| 视图 | 用户能看什么 | 数据来源 |
| --- | --- | --- |
| 利润表现 | 切换营业收入、归母净利润，比较本期和上年同期；看到金额差与适用时的同比百分比 | 本版利润表 |
| 三类现金流 | 经营、投资、筹资活动的两期净额，共用零线，保留净流入与净流出方向 | 本版现金流量表 |
| 净额拆解 | 上年经营净额 → 流入变化贡献 → 流出变化贡献 → 本年经营净额 | 已核验的同一份原始合并现金流量表 |

每个视图可以切换“图表／数据”。点击或用键盘选中柱形，会显示具体金额与含义；“围绕这项继续提问”将公司、期间和选中的数值带入输入框，用户可编辑后发送。来源入口沿用现有证据抽屉。

有原始分项时默认展示净额拆解；没有对应来源时不展示该图。图表随每版已发布的取证与核验结果重新计算，不重新调用模型，也不修改历史事实、用户观点或记忆。当前不是实时行情，也没有逐条数据到达时的流式绘图。

## 实现边界

采用固定 React/SVG 图表组件与确定性数据合同，保留现有 UI 基础，不增加大型图表运行依赖；不是由模型生成任意 HTML 或可执行代码。图形读 `rawFields`，不从自然语言回答里猜金额。

匹配公司、scopeKey、年度／累计季度、人民币元及允许的数据来源；重复期间、未知单位或币种不绘图。缺失不填零；上年基数小于等于零不输出普通增长率。金额已在取证层归一为元，原始千元表不会再次乘1000。累计季度明确标注一季度累计、上半年累计、前三季度累计或全年累计。

利润与营收分别成图，切换时独立调整刻度。三类活动净额不强行等同现金净增加。瀑布锁定本版指定的 PDF，重新复算收支差额，不拼接旧接口净额；贡献正负表示对净额的算术影响，不代表投资质量评级。
