# UI 工作台迭代与验收

日期：2026-10-15。范围：现有 React 投资研究界面的阅读、导航和响应式交互。

## 本轮取舍

保持一个主 Bot 的标准聊天界面。主区优先显示已有结果的阶段判断、依据与解释、关键未决条件；研究对象、本轮关注和记忆使用状态移至上下文栏。1280px 起可并排展开，窄屏使用抽屉。研究和核验 Bot 保留真实交流，并提供本轮／全部记录筛选。

没有修改模型、数据接入、长期记忆写入策略或原有任务结果。界面显示的是已有任务的真实保存状态；截图中的演示关注不代表用户投资偏好。

## 改动

- 统一正文、辅助文字、间距、边框、颜色和交互状态，提高长回答的可读性。
- 首页突出接续研究，新的问题作为列表入口；点击仅填入问题，用户仍需发送。
- 桌面上下文栏展示实际公司、期间、关注点、记忆来源及保存状态；移动端按需打开。
- 答案顶部显示已有 `result.summary`，保留主张与证据支持状态，缩短来源按钮的显示名称，保留完整可访问名称。
- Bot 记录默认只看当前 revision，历史仍可切换查看；工具返回可展开。进度提示仅取当前 revision 的工作消息。
- 保留 Gooey 辅助按钮、原始依据和完整 Trace 链接。Bot 标签支持方向键、Home、End。
- 记忆编辑自动聚焦，取消后回到原按钮；删除记忆新增内联确认，未执行实际删除。
- 窄屏侧栏关闭时不再保留可聚焦的隐藏控件，抽屉支持焦点圈和关闭恢复。
