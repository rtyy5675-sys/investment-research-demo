# 通用 A 股财报研究

## 产品任务

用户提供公司名称或代码、报告期和研究问题。助手确认范围，查询财务数据，解释证据支持什么、哪些部分仍待核实，并在资料不足时指出下一步可做的补查。记忆用于接续用户明确的关注点和未解决的问题，不把历史判断当作当前事实。

## 当前支持

- 单家 A 股公司；通过扶摇 Meta MCP 检索公司代码，遇到歧义时先澄清。
- 利润表、现金流量表和资产负债表；按问题选择查询。
- 年报和一季度、上半年、前三季度累计报表；财务字段按报告期与统计口径比较。
- 普通追问沿用当前任务范围；公司或期间变化后重新取数并隔离旧范围证据。
- 通过公告检索或上传文本型 PDF 补查已支持的原始财报字段。

## 研究流程

1. 从用户问题和本轮明确上下文识别公司、期间与关注点。
2. 通过 Meta MCP 检索并确认标的。
3. 调用财务工具取得目标期间及可比期间的数据。
4. 检查单位、期间、累计或时点口径及证据引用，再形成阶段判断。
5. 对可补查问题检索原始披露，更新相关判断并保留仍未解决的部分。

任务状态区分运行、完成、需要澄清和失败。失败时保留上一版结果及其原范围。MCP 连接检查只验证服务和工具发现；具体数据是否取得以研究中的工具记录为准。

## 能力边界

当前范围是单家 A 股财报研究。多公司横向比较、港美股、市场预期、估值和股价判断不属于已接入能力。现金流 PDF 补查限已实现的字段抽取与核验，不等于任意财报问答。累计季度数据不用于推算单季度差分；资料源缺少目标期间时应明确说明。

工具查询时间不等于信息首次公开时间。上游数据可能重述，行业特殊科目需单独判断。系统不预测收益、不执行买卖，也没有长期用户价值验证。

## 运行与验收

本机启动：`npm ci` 后运行 `npm start`。模型 API 和扶摇凭证通过本机界面及 `.env.local` 配置。验收入口、演示、测试说明和运行边界见[评审入口](评审入口.md)。
