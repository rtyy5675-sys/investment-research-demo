# 主演示：补上上次缺的资料，让判断向前一步

日期：2026-10-15。实际模型、扶摇MCP和公开原始年报。输入是产品验收设计，非真实用户访谈或投资偏好。

## 1. 任务与首轮输入

用户连续研究同一家公司，上次只确认经营现金流净额下降，尚不知道流入与流出分别怎样变化，希望工具接着查。

> 请研究贵州茅台（600519.SH）2025年全年经营现金流净额相对2024年的变化。我想弄清主要是流入变化还是流出变化造成；先基于当前结构化报表回答，缺少分项时保留这个未决问题。

验收基线主动关闭自动公告补查，以观察前后差异；正常产品发现对应缺口后会尝试取证。资料来自真实服务，不是手填数值。

## 2. 首次结果：知道变化，尚不能拆分贡献

实际扶摇返回2024年经营净额924.64亿元，2025年615.22亿元，减少309.41亿元，但没有所需收支分项。

系统留下“经营现金流入和流出分别如何变化，哪一侧贡献更大”的未决问题。没有直接将净额下降解释成销售回款变差，没有把疑问记作用户的肯定立场。

## 3. 一次补查：取得原始披露

按代码和期间检索到[贵州茅台2025年年度报告](https://static.cninfo.com.cn/finalpage/2026-04-17/1225114741.PDF)，PDF第64–65页合并现金流量表，单位元。模型提取后，程序核对公司、期间、单位、列位、逐字引文和两期收支勾稽。

| 项目，亿元 | 2024年 | 2025年 | 变化 |
| --- | ---: | ---: | ---: |
| 经营活动现金流入 | 2,000.86 | 1,861.29 | −139.58 |
| 经营活动现金流出 | 1,076.23 | 1,246.07 | +169.84 |
| 经营活动现金流净额 | 924.64 | 615.22 | −309.41 |

按原始元值计算，展示存在舍入尾差，不补造其他贡献。

## 4. 判断怎样改变

实际模型由“缺少分项，无法区分”更新为“流入减少与流出增加共同压低净额，流出增加的算术贡献较大”。原表还显示销售收款增加13.45亿元，因此不能把全部净额下降等同于销售收款减少。

**这次解决的：**两侧变化及各自贡献。

**仍未解决的：**更细项目为何变化、是否持续、是否说明回款质量变化。算术拆分不是经营因果证明。

界面用瀑布图、数据表和原文页码呈现；点选可带入追问。图表读取该版结构化证据，不让模型另造数值。

## 5. 换公司验证通用性

美的相同问题使用PDF上传。[美的2025年年度报告](https://static.cninfo.com.cn/finalpage/2026-03-31/1225065145.PDF)第137页为合并及公司现金流量表，单位千元，四列并排。程序取合并两列、换算后确认：流入增加367.67亿元，流出增加439.33亿元，净额减少71.66亿元。

这是“两侧均增”的不同情形，没有套用茅台答案；美的未取得利润表，所以不显示利润图。该路径完成真实模型回答及最终核验。

## 6. 真实失败

独立茅台任务成功后，故意上传美的PDF：公司校验失败，任务为partial，上版有效结果逐字段保留。过期revision上传被拒绝。

实际提取还出现模型扩写单位、年度列，严格引文校验拒绝。修正提取合同并在预算内允许一次修复，未放宽引文和算术标准。
