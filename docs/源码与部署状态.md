## Render 创建入口

[使用本仓库创建 Render Blueprint](https://render.com/deploy?repo=https://github.com/rtyy5675-sys/investment-research-demo)

此链接是部署配置入口，不是产品 Web URL。后续重建服务时，需完成 Render 登录、应用根目录的 `render.yaml`、填写服务端环境变量，再从控制台复制实际分配的域名。

配置：Node 24.21.0，Free，构建 `npm ci --include=dev && npm run build`，启动 `node server.mjs`，健康检查 `/healthz`。模型和扶摇凭证仅填入 Render Environment。保留访问密码；研究记录在免费实例重启后不保证保留。

公开版本排除了旧提交历史、本地研究记录、API Key 和原始调用记录；保留测试摘要与截图。发布前在干净副本执行 `npm ci`、153 项单元测试和前端构建，均通过。完整产品验收仍有已知未通过项，见系统性测试报告。

## 后续更新

本服务通过公开 Git URL 连接，没有授予 Render GitHub App 访问权限。更新代码后，在 Render 的 `Manual Deploy → Deploy latest commit` 部署；修改 `render.yaml` 时需在 Blueprint 手动同步并审查变更。不要假定每次推送都会自动部署。
