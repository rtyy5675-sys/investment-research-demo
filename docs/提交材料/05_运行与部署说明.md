## 二、本机启动

需要 Node.js 20.19 或更新版本；当前 Render 使用 24.21.0。

```sh
npm ci
npm start
```

本机默认打开 `http://127.0.0.1:8791`。`npm start` 会构建前端后启动服务；不要把 localhost 当作公网交付链接。

模型可在“模型 API”入口配置，或通过环境变量：

```env
MODEL_PROVIDER=openai-compatible
MODEL_BASE_URL=https://api.deepseek.com
MODEL_NAME=deepseek-flash
MODEL_API_KEY=<your-model-key>
FUYAO_API_KEY=<your-fuyao-key>
```

这里只展示变量名和占位符，不包含可用 Key。真实值仅放在本地忽略文件或部署平台服务端环境变量。当前真实测试覆盖 DeepSeek 与本机 Codex CLI；兼容格式不代表所有模型已验证。iFinD 没有接入。

## 三、Render 部署

根目录 `render.yaml` 声明 Free Node Web Service：

- 构建：`npm ci --include=dev && npm run build`
- 启动：`node server.mjs`
- 健康检查：`/healthz`
- 环境：`NODE_ENV=production`、`HOST=0.0.0.0`、`RESEARCH_STORAGE_MODE=ephemeral`
- 认证：`PREVIEW_ACCESS_USERNAME`、`PREVIEW_ACCESS_PASSWORD`

`/healthz` 只证明服务存活；模型和取证是否正常仍要实际调用。当前生产代码部署记录为 `f09732703f1fca02621e5d12f37ab8ff4adba940`，后续提交材料只修改文档，不能据此声称代码重验。

服务通过公开 Git URL 连接，没有授予 Render GitHub App 权限；更新代码后在控制台 `Manual Deploy → Deploy latest commit`，修改 Blueprint 时手动同步并核对变更。

## 四、存储与运行限制

免费实例可能休眠，首次访问会等待；实例休眠、重启或重新部署后记录不保证保留。本次可以在同一存活实例内用多个会话展示续接，长期云端记忆属于后续迭代。

每轮默认总时长 240 秒、最多 4 次模型和 8 次工具尝试、120000 已报告 Token、48000 输入字符。供应商未报告的用量为未知，Token 预算不是绝对费用上限。仍有较大的前端 bundle 提示，首屏和延迟需要后续优化。

## 五、ZIP 浏览与凭证处理

先解压完整目录，再打开入口、离线阅读页或源码目录；相对链接和截图需要保持原位置。不要依赖压缩包未解压时的文件跳转能力。

提交包不含 `.git`、依赖、构建产物、`.env.local`、个人记忆、原始 Trace 或模型 Key。单独的 Web 访问凭证只交给评审，不上传 GitHub。演示脚本不是视频，未录制时不列为已完成交付。
