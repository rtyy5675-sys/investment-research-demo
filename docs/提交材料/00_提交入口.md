## 这是什么产品

见微的长期方向是 personal agent：持续理解一个人为什么关注某家公司、研究到了哪里、还有什么疑问，让用户不必每次从头交代，也不必提醒“这一步已经查过”。

本次以单家 A 股财报研究承载最小链路：**提出问题 → 接续相关研究背景 → 获取财务数据 → 解释与补查 → 更新已解决与未决问题 → 用户纠正后继续。**长期产品方向已确定；长期用户价值仍需验证。
