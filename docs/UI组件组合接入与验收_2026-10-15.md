# UI 组件组合接入与验收

## 选择与落地

按用户选择，以 C（prompt-kit）为主，A（assistant-ui）补充，B（shadcn/ui）提供公共基础。三者复用源码并共享同一主题，任务仍由原服务驱动。

| 来源 | 实际接入 |
| --- | --- |
| C / prompt-kit | Message、Avatar、MessageActions、PromptInput、ChatContainer、Source；已有业务 Markdown 保留并补充 GFM 表格 |
| A / assistant-ui | 独立 RunActivity，呈现当前版本的公开工作记录、调用用量及 Trace 入口 |
| B / shadcn/ui | Button、Tooltip、Tabs、DropdownMenu、Sheet、Collapsible、HoverCard |

未接入第二套聊天运行时。保留原发送、停止、任务版本、MCP、记忆 CRUD 与失效政策。没有改后端与系统 Prompt。新增依赖固定在 package-lock.json；来源和许可见 THIRD_PARTY_NOTICES.md。

## 已观察的验收结果

验收用已有会话 `744cd450-ae56-43da-9ff7-0df72df4dd54` 第 2 版；其演示偏好仍明确标注“不代表真实偏好”。未发送新研究问题，未产生新的模型或财务查询。

- `npm run build` 通过。Vite 仍提示主 JS 大于 500 kB；当前主 JS 约 668 kB、gzip 208 kB，后续可按面板拆包；未通过放宽阈值隐藏警告。
- 1440×900 桌面显示导航、对话、研究上下文；390×844 手机显示单列对话和抽屉；实际读取未发现页面横向溢出。
- RunActivity 展开显示实际当前版本工作记录、用量和完整 Trace 链接；最终回答在折叠区外。
- Bot 标签页可通过 ArrowRight 切换，实际显示对应 Bot 工作记录。
- 更多菜单正常打开；当前会话的数据来源和执行方式保持禁用；Escape 可关闭菜单。
- 顶部依据入口及 prompt-kit 行内引用可打开资料抽屉；已修复引用悬浮预览延迟覆盖抽屉的问题，复查抽屉打开时预览数为 0。
- 手机“上下文→管理→修改→取消→关闭”可完成；未保存改动。修复记忆管理关闭后焦点落到 body 的问题；复查返回“研究上下文”按钮。
- 受控输入填入中文文本后，Shift+Enter 保留换行、未提交。空输入时发送禁用。
- “回到对话底部”点击后进入底部，按钮隐藏；内部保留一个实际滚动容器，外层 overflow:hidden。
- Gooey 辅助入口可展开资料、修改问题两个按钮。
- 浏览器日志只观察到 Zotero 扩展连接错误，未观察到本应用异常。

## 未宣称完成的验证

本轮未重新跑金融语义评测、真实发送/停止、异常恢复与记忆写入回归；这些业务机制沿用现有代码。中文 IME 防误提交做了代码适配，但尚未进行真实输入法候选状态的人工验证；系统软键盘、读屏与 Safari 尚未实测。没有将构建或视觉检查视为研究质量证明。
