# 模型 API 配置入口

日期：2026-10-15。已接入右上角“模型 API”和更多菜单中的“模型 API 与数据连接”。

## 操作

1. 选择本机Codex，或OpenAI兼容API。
2. 兼容API填写基础地址、服务商模型ID和Key，保存。完整`/chat/completions`地址也会归一为基址，不重复拼接。
3. 点击“验证模型”，实际发起一次基础JSON Schema模型请求；不会读取用户研究数据，可能产生少量Token费用。
4. 保存后新研究使用对应配置，不需重启。运行中禁止切换，每轮研究也固定开始时的配置快照。

不返回已有Key，不保存在浏览器localStorage，保存成功清空密码输入。Key空白表示保留；更换服务主机必须显式填写对应新Key。配置以权限600原子写入被Git忽略的`artifacts/model-settings.json`；提交包排除整个artifacts。

本地保存配置优先于环境变量；未配置时保留原环境/本机Codex路径。模型接口需支持严格JSON Schema，基础检查不能证明复杂研究Schema或全部语义正确。

## 接口

| 接口 | 用途 |
| --- | --- |
| GET `/api/model-settings` | 返回基址、模型名、是否有Key、版本及上次成功验证时间，不返回Key |
| POST `/api/model-settings/save` | 版本检查、参数验证、服务端保存 |
| POST `/api/model-settings/check` | 使用已保存配置发起一次真实适配器调用，返回安全的验证说明 |

设置写入只接受本机、JSON和同源请求；阻止跨站修改。自定义请求不跟随重定向转发Key。这不是多人部署的权限系统；远程部署前仍需单独处理访问与隔离。
